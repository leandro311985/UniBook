Política de Privacidade do DISCÍPULO

Última atualização: 19 de novembro de 2026

Esta política explica como o aplicativo DISCÍPULO trata os dados usados para registrar e acompanhar atendimentos pastorais. Esses registros podem revelar vínculo religioso e incluir informações pessoais ou delicadas compartilhadas durante um atendimento. Cadastre somente dados necessários e obtenha as autorizações aplicáveis das pessoas envolvidas.

Responsável e contato

Responsável pelo aplicativo: Leandro Alves de Oliveira. Para dúvidas, solicitações ou exercício de direitos relacionados a dados pessoais, escreva para leandro.alves311985@gmail.com.

Dados tratados

  • Perfil do usuário: nickname, telefone e função ou ministério. O perfil é salvo no dispositivo; nickname e telefone também são enviados ao serviço para associar os dados.
  • Atendimentos: nome, endereço, bairro, telefone, e-mail, situação na igreja, informações relatadas, cultos, responsável pelo acompanhamento, data, observações, grupo e foto, conforme preenchidos.
  • Identificador do dispositivo: um identificador aleatório usado para associar as solicitações do aplicativo aos dados no serviço.
  • Configurações locais: nome e imagem da congregação, quando informados.

Finalidades e compartilhamento

Os dados são usados para manter o perfil, registrar, consultar, atualizar, sincronizar e excluir atendimentos e obter lembretes solicitados pelo serviço. Quando há conexão, o aplicativo transmite dados à API em unibookback.onrender.com por HTTPS. O aplicativo não integra SDKs de anúncios ou de analytics. O serviço de API e os provedores técnicos necessários para operá-lo podem processar os dados para prestar essas funções; dados não são vendidos pelo aplicativo.

Armazenamento, segurança e retenção

No Android, os dados locais do aplicativo são criptografados com AES-GCM usando uma chave do Android Keystore, e o backup do aplicativo está desativado. No iOS, os dados locais são guardados nas preferências do sistema (NSUserDefaults), sem criptografia adicional implementada pelo aplicativo. A comunicação com a API usa HTTPS.

Os dados mantidos pelo serviço são retidos por até um ano. Atendimentos podem ser excluídos no próprio aplicativo; se o dispositivo estiver offline, a exclusão local será sincronizada quando houver conexão. O perfil não tem exclusão no aplicativo: para solicitar sua exclusão antes do prazo, use o contato informado acima. Desinstalar o aplicativo remove os dados locais do dispositivo, mas não exclui dados já enviados ao serviço.

Lembretes e notificações

No Android, o aplicativo pode consultar lembretes do serviço e exibir notificações locais. A permissão de notificações pode ser negada ou revogada nas configurações do dispositivo. As notificações usam texto genérico para reduzir a exposição de informações pessoais na tela bloqueada.

Direitos e solicitações

Você pode solicitar informações, correção ou exclusão de dados pessoais pelo e-mail de contato. A exclusão de um atendimento também pode ser feita no aplicativo. Para dados sincronizados, a solicitação depende de conexão com o serviço ou do atendimento do pedido por e-mail.

Alterações desta política

Esta política pode ser atualizada para refletir mudanças no aplicativo ou no tratamento de dados. A versão vigente será publicada nesta página com a data de atualização.
